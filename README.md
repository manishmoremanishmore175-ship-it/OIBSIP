# Manish Academy – Landing Page

## Project Overview
Manish Academy is a modern and responsive educational landing page developed as part of the Oasis Infobyte Web Development & Designing Internship.

The website provides information about the academy, available courses, learning opportunities and contact details.

## Technologies Used
- HTML5
- CSS3
- Google Fonts

## Features
- Professional navigation bar
- Attractive hero section
- About Our Academy section
- Popular courses section
- Why Choose Us section
- Contact information
- Responsive design for mobile and desktop
- Smooth scrolling and hover effects

## How to Run
1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

## Project Structure
- index.html – Website structure
- style.css – Website styling
- README.md – Project documentation
